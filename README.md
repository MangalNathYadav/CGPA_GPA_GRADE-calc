# Grade & GPA Calculator 🎯

A premium, modern web application for calculating Semester GPA and Cumulative GPA (CGPA) with support for both **Absolute** and **Relative** grading methods (specifically tailored for VIT Bhopal's 10-point scale).

## 🌟 Features

- **📊 GPA Calculator**: 
  - Add courses dynamically with credits and marks.
  - Supports **Absolute Grading** (fixed percentage ranges).
  - Supports **Relative Grading** (curve-based using class mean, standard deviation, and highest/lowest marks).
  - Handles passing criteria (TEE and CAT percentage requirements).
- **🎓 CGPA Calculator**:
  - Add multiple semesters with their respective credits and GPA.
  - Computes cumulative GPA across all recorded semesters.
- **📋 Grading Scale Reference**:
  - Detailed breakdown of the 10-point scale (S, A, B, C, D, E, F).
  - Explanation of mathematical boundaries for relative grading.
- **💾 Local Persistence**: Automatically saves your entered courses and semesters to your browser's local storage.
- **🎨 Sleek & Minimalist UI**: Clean layout, badge indicators, and smooth animations without heavy external libraries.

## 🚀 Tech Stack

- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS with customized design tokens

## 💻 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MangalNathYadav/CGPA_GPA_GRADE-calc.git
   cd CGPA_GPA_GRADE-calc
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **View the app**:
   Open your browser and navigate to [http://localhost:3000](http://localhost:3000).
